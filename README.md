# 🌐 HTML, CSS & JavaScript Foundations

A collection of practice projects and challenges focused on building a strong foundation in core web development: semantic HTML, responsive CSS, and JavaScript logic.

---

## 🎯 Focus Areas

- **HTML:** Clean semantic markup, proper structure, and forms.
- **CSS:** Flexbox, CSS Grid, responsive design, and styling fundamentals.
- **JavaScript:** DOM manipulation, event handling, functions, and core logic.

---

## 📁 Projects

- **Rock, Paper, Scissors Game:** Interactive browser game featuring randomized computer choices, score tracking, dynamic DOM updates, and outcome validation.
- **Simple Calculator:** Arithmetic calculator implementing core math operations, real-time input parsing, button click listeners, and clear/reset functionality.
- **Coin Flip Simulator:** Random chance simulator utilizing `Math.random()` to determine heads or tails with dynamic visual feedback and toss history.

---

## 🚀 How to View

1. Clone or download this repository.
2. Open any project folder and launch `index.html` in your browser (or use the VS Code Live Server extension).
